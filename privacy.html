Privacy Policy

Effective date: 25 October 2026

This page explains the data handling associated with ShortForge AI, based on the published application code and its intended operation. Hosting providers and third-party services may process technical information under their own policies.

Data handled by the application

  • Video uploads: the browser-upload workflow sends the selected video and transcript to the ShortForge API to create analysis results, thumbnails, and clips.
  • Processing files: source videos, generated previews, thumbnails, and clips are temporarily stored on the processing server. The API schedules job folders for automatic cleanup after 24 hours. This is an operational retention target, not a guarantee that every backup or hosting log is deleted at exactly that time.
  • YouTube processing: when using the local bridge, video download and transcription are performed on your device; the source video and transcript may then be sent to the processing API for clip generation.
  • Cookies files: if a client uploads a YouTube cookies file directly to the API, it is used for that job and deleted after analysis. Never upload browser profile files or cookies you do not own or have permission to use.
  • Technical data: the hosting provider may process request metadata, IP addresses, error logs, and operational records to deliver and secure the service.

How to reduce data exposure

Only upload videos you have rights to use. Avoid videos containing sensitive personal information. Download results you need and do not share job-specific media URLs; anyone who obtains a job URL may be able to access that file until it expires or is deleted.

Service providers and external links

The frontend currently loads the Phosphor icon library from unpkg and the browser speech-recognition runtime from jsDelivr; the runtime may also fetch model files from Hugging Face. These providers can receive your IP address, browser request metadata, and requests for the resources. Speech inference runs in the browser, but model files are downloaded from the provider. The page uses the system font stack rather than loading fonts from Google Fonts.

ShortForge AI is hosted through GitHub Pages and a separate processing API hosted by the project. The API may receive source videos, transcripts, generated clips, and (only if a client uploads it to the API) a cookies file. Links to third-party sites, repositories, application publishers, and services are governed by their own privacy policies. We do not control those services.

Retention and deletion

Where this application stores information in your browser, you can generally remove it by clearing the relevant site data. This may permanently remove local documents, preferences, or installed-app records. Server-side files, if any, follow the retention described above. Do not submit passwords, session cookies, access tokens, or other secrets unless a feature explicitly requires them and you understand the risks.

Children

This project is not intentionally designed to collect personal information from children. If you believe personal information was submitted inappropriately, contact the maintainer using the project’s GitHub repository. Do not post personal or sensitive details in a public issue.

Changes and contact

This policy may be updated when the application’s data practices change. For questions or privacy requests, use the contact method listed on the VRuntime Labs GitHub profile. Do not include sensitive information in a public issue. A dedicated privacy contact should be published before broad public launch.
